# Sanjay — Portfolio

A personal portfolio landing page built from scratch with hand-written CSS (no framework).

## Tech stack
- HTML5
- Custom CSS (`style.css`)
- Font Awesome 4.7.0 (CDN)
- Google Fonts — Space Mono

## Sections
- Hero intro
- About Me
- Stats counters (years freelancing, websites designed, years in digital marketing)
- "What I Do" services (WordPress Development, Social Media Marketing, SEO, SEM)
- Recent Work
- Contact / "Let's Collab"

## How to run
Open `index.html` directly in a browser. No build step or server required.

## Known limitations
- Stats counters currently show placeholder values (e.g. "00" years).
- "Recent Work" portfolio links are placeholders (`href="#"`).
- Contact section contains real contact details (phone/email) hardcoded directly in the HTML — keep this in mind before publishing this project publicly (e.g. a public GitHub repo or live site).
